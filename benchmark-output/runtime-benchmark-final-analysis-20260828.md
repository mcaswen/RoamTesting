## 3. 核心结论

1. 默认路径下，DOD 的平均帧耗时比 Classic 低 26.15%，P95 低 23.00%，P99 低 27.61%；CBT 的平均帧耗时比 Classic 低 93.24%、比 DOD 低 90.85%。
2. 极限路径下，DOD 的平均帧耗时比 Classic 低 41.04%，P95 低 37.02%，P99 低 32.31%；CBT 五轮合并平均比 Classic 低 99.53%、比 DOD 低 99.21%。
3. DOD 的主要收益来自候选扫描：默认路径 merge mark/split scan 分别下降 61.56%/69.42%，极限路径下降 81.08%/85.69%。DOD 的 topology commit 并未同步变快。
4. 极限路径中，DOD split topology 比 Classic 高 0.56%，merge topology 高 24.00%；DOD split topology 几乎全部耗在串行收敛，仍是明确瓶颈。
5. CBT 极限路径的五轮 P99 为 16.574 ms，但该尾部完全由第 1 轮异常贡献。第 2～5 轮合并后，CBT 平均为 0.452 ms、P95 为 0.692 ms、P99 为 0.996 ms，轮间 CV 为 5.08%。
6. 三角形规模已经对齐：默认路径 CBT 比 CPU 两算法平均少 0.138%，极限路径平均多 0.906%。极限路径 CBT 没有 200K 硬预算，最大仍会达到 216723。

## 11. 最终判断

在 1280×720 且三角形规模已经校准后，三种算法的性能层级在五轮中没有发生反转：CBT 明显领先，DOD 明显领先 Classic。DOD 的主要价值是用数据导向布局和并行候选评估降低全局扫描成本，但 topology commit 和部分 finalize/upload 路径仍抵消了一部分收益；CBT 则把 LOD 决策、拓扑维护、几何生成和绘制参数留在 GPU，避免了大规模 CPU 遍历与每帧 mesh upload。

五轮数据也表明，单轮 benchmark 不足以代表稳定性能。默认路径 DOD 的轮间 CV 达 18.98%，第 1 轮极限路径还出现了跨算法 render 变慢及 CBT fence/GPU timing 异常。若要冻结正式论文或发布基线，建议继续采用至少五轮重复，并补充以下控制：记录可执行文件 SHA-256、锁定 CPU/GPU 电源状态、按算法拆分独立进程并轮换执行顺序，同时报告 pooled P95/P99、轮间 CV 和包含/排除异常轮的敏感性分析。
